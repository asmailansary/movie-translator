# مترجم الأفلام 🎬

تلصق رابط فلم من يوتيوب ما فيه ترجمة عربية، وتختار لغة الفلم (إنجليزي / ألماني / فرنسي / تلقائي) واللهجة اللي تبيها (فصحى، نجدية، حجازية، خليجية، يمنية، مصرية، شامية، عراقية)، وتتابع الفلم والترجمة تمشي عليه متزامنة.

**كل شي مجاني وما يحتاج بطاقة.**

## كيف تشتغل

```
جوالك ──▶ Cloudflare Worker ──(يشغّل)──▶ GitHub Actions
   ▲            │  ▲                          │
   │            │  └──── الترجمة أول بأول ◀──┘
   └── الفلم + الترجمة ─┘ (محفوظة في R2)
```

| الجزء | وين يشتغل | المهمة |
|---|---|---|
| الصفحة وكلمة المرور | Cloudflare Worker | تفتحها من جوالك |
| حفظ الترجمات | Cloudflare R2 | الفلم اللي ترجمته مرة ما يترجم مرة ثانية |
| تحميل الصوت وتقطيعه | GitHub Actions | `pipeline/translate.py` |
| تحويل الكلام لنص | Groq Whisper (مجاني) | ساعتين صوت كل ساعة، 8 ساعات باليوم |
| الترجمة | Google Gemini Flash (مجاني) | و Groq احتياط لو خلص حد Gemini |

## الملفات

| الملف | وش فيه |
|---|---|
| `worker/src/index.js` | كود Cloudflare Worker |
| `worker/public/index.html` | الصفحة اللي تشوفها |
| `wrangler.toml` | إعدادات Cloudflare |
| `pipeline/translate.py` | التحميل والتفريغ والترجمة |
| `.github/workflows/translate.yml` | يشغّل `translate.py` على GitHub |

## الأسرار

**في GitHub** (Settings → Secrets and variables → Actions):

| الاسم | المحتوى |
|---|---|
| `GROQ_API_KEY` | من console.groq.com |
| `GEMINI_API_KEY` | من aistudio.google.com |
| `INGEST_SECRET` | كلمة سر طويلة تختارها (نفسها في Cloudflare) |
| `YT_COOKIES` | اختياري، فقط لو يوتيوب منع التحميل |

**في Cloudflare** (Worker → Settings → Variables and Secrets):

| الاسم | المحتوى |
|---|---|
| `GH_TOKEN` | مفتاح GitHub بصلاحية Actions على هذا المستودع فقط |
| `INGEST_SECRET` | نفس اللي في GitHub |

## الاستخدام
1. الصق رابط الفلم واختر **لهجات ← نجدية**.
2. اضغط **ترجم وشغّل**.
3. GitHub يأخذ قرابة دقيقة يبدأ، وبعد أول جزء تقدر تشاهد والباقي يكمل.

- **وضع السينما**: يملأ الشاشة والترجمة فوق الفلم. اقلب الجوال بالعرض.
- **حجم الخط** و**تقديم/تأخير الترجمة**.
- **ملف الترجمة**: ينزّل `.srt`.

من Safari: مشاركة ← **إضافة إلى الشاشة الرئيسية**.

## مزايا المشاهدة
- **مشغّل خاص:** بدون واجهة يوتيوب. لمسة وحدة تظهر الأزرار، و**لمستين** يمين أو يسار تقدّم أو ترجع ١٠ ثواني.
- **تبديل اللهجة وانت تتفرج** (حتى الفصحى) من زر 🗣️ أو ⚙️، والفلم ما يوقف.
- **سرعة التشغيل**، وحجم الخط، وتوقيت الترجمة، والكلام الأصلي، كلها من ⚙️.
- **وضع السينما** مثل نتفلكس. افتح قفل التدوير واقلب الجوال عشان تختفي الساعة.
- **المحفوظة ❤️:** تحفظ الفلم ومكانك فيه، وترجع له من الصفحة الرئيسية.
- **تطبيق + إشعارات 🔔:** أضف الأداة للشاشة الرئيسية من Safari (وخلّ «فتح كتطبيق ويب» شغّال)، وفعّل التنبيهات، ويوصلك إشعار أول ما يجهز فلمك. الإشعارات ما تحتاج أي إعداد إضافي، والمفاتيح تتولد تلقائياً وتنحفظ في R2.

## لو يوتيوب منع التحميل (الكوكيز)
- استخدم **حساب Google ثانوي** مو حسابك الأساسي.
- من كمبيوتر: سجّل دخول يوتيوب بالحساب الثانوي، ثبّت إضافة **Get cookies.txt LOCALLY**، صدّر كوكيز youtube.com، والصق المحتوى في سر GitHub اسمه `YT_COOKIES`.

## الأمان
- المفاتيح في أسرار GitHub و Cloudflare فقط، ما توصل للمتصفح ولا للكود.
- بدون كلمة مرور: كل جهاز له رمز عشوائي خاص فيه، فمحفوظته وإشعاراته له بس، والترجمات مشتركة بين الكل.
- حد يومي للأفلام الجديدة (8 لكل جهاز، 30 للكل) عشان ما تخلص الحدود المجانية. تقدر تغيّره بمتغيرات `DAILY_PER_DEVICE` و`DAILY_TOTAL` في Cloudflare.
- GitHub يرسل الترجمة لـ Cloudflare بكلمة سر خاصة (`INGEST_SECRET`)، فما أحد غيره يقدر يكتب ترجمات.
- مدخلات GitHub Actions تمر كمتغيرات بيئة (مو داخل السكربت) ويتحقق منها قبل التشغيل.
- يقبل روابط يوتيوب فقط ويتحقق من صيغة معرّف الفيديو.

الأداة للمشاهدة الشخصية؛ لا تعيد نشر ترجمات أعمال غيرك بدون إذن أصحابها.
